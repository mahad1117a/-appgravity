# 🚀 Apps Gravity — Full-Stack Platform & AI Assistant

Welcome to the official repository for **Apps Gravity**, founded by **Hassan** (`@mahad1117a`). 

Apps Gravity is a futuristic, luxury-styled full-stack platform dedicated to custom **Mobile App Development**, **Web Development**, **AI-Powered Visitor Assistance**, and **Free Professional Course Distribution**.

---

## 🌟 Features & Highlights

- **🤖 GravityBot AI Visitor Assistant**: Floating AI chat widget with a 150+ entry structured knowledge base (web dev, mobile dev, programming, cybersecurity, data & analytics, AI, medical billing, business/freelancing), quick action prompt chips, a Wikipedia-powered quick-answer + direct Google search link for anything outside that, and backend REST API integration (`/api/chat`).
- **🧮 Interactive Project Estimator**: Live cost and turnaround time calculator for Web Apps, Mobile Apps, and Full-Stack Systems with custom feature add-ons.
- **📚 Searchable Free Courses Hub**: Expandable course library featuring **Medical Billing Complete Video Course** (hosted on Google Drive) alongside Web Dev, Mobile App, and Python automation courses with real-time search & filter chips.
- **📱 Pak Advisory App Interactive Showcase**: Modal preview featuring app structure, features, tech stack, and inquiry bridge.
- **⭐ Client Testimonials & Review System**: Interactive review cards with real-time review submission modal.
- **⚡ Express Backend Server**: Node.js & Express API endpoints for AI chat, project quotes, course distribution, review posting, and contact form handling.
- **✨ Luxury & Futuristic Aesthetic**: Built with deep dark mode gradients, metallic gold accents, glow effects, interactive cursor tracking, and a dynamic background particle engine.

---

## 🛠️ Built With

- **Frontend**: HTML5, CSS3 (Glassmorphism, Keyframe animations, CSS Grid/Flexbox), JavaScript (ES6+).
- **Backend API**: Node.js, Express, CORS, RESTful Endpoints.
- **Fonts**: *Orbitron*, *Rajdhani*, and *Inter*.

## 🚀 How to Run Locally

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Full-Stack Server**:
   ```bash
   npm start
   ```

3. **Access Web Application**:
   Open [http://localhost:3000](http://localhost:3000) in your browser.
